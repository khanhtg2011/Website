🔧 WHAT TO LOOK FOR AT EACH STEP:

**Step 1 - test_feedback_api.php:**
✅ Should show: "✅ photo_feedback table exists"
✅ Should show: "✅ feedback.php file exists"
✅ Should show: "✅ feedback.php is readable"
❌ If shows errors, fix database/PHP issues first

**Step 2 - feedback_simple.php:**
✅ Should return: {"stats":{...},"comments":[],"message":"Simple feedback API working"}
✅ Content-Type header should be: application/json
❌ If returns HTML, there's a PHP fatal error

**Step 3 - Modal in Gallery:**
✅ Modal opens when clicking photos
✅ Rating stars are visible and clickable
✅ Console shows: "Feedback API response: {...}"
❌ Console errors indicate JavaScript issues

**Step 4 - Feedback Submission:**
✅ Clicking submit shows success message
✅ Console shows: "Submit response data: {...}"
✅ Stats update after submission
❌ Errors indicate API communication issues

📊 DEBUGGING CHECKLIST:

□ Database Connection:
  - config.php loads without errors
  - Database credentials are correct
  - MySQL server is accessible

□ File Permissions:
  - feedback.php is readable (644)
  - uploads/ directory is accessible
  - PHP can write to necessary directories

□ PHP Configuration:
  - No fatal errors in feedback.php
  - JSON extension is enabled
  - Error reporting is configured properly

□ JavaScript Loading:
  - Functions are defined when modal opens
  - No console errors about undefined functions
  - Event listeners are properly attached

□ Network Requests:
  - API calls return HTTP 200
  - Content-Type is application/json
  - No CORS errors in console

🚨 COMMON ISSUES & SOLUTIONS:

**Issue: "Table doesn't exist"**
Solution: Run setup_feedback_table.php

**Issue: "Function undefined"**
Solution: Hard refresh browser (Ctrl+F5)

**Issue: "Network error"**
Solution: Check PHP error logs, fix database connection

**Issue: "HTML instead of JSON"**
Solution: Fix PHP fatal errors, check file permissions

🔄 SWITCHING BACK TO FULL API:

Once the simple API works, update index.php:

