🚀 HOW TO USE:

1. Login as admin user
2. Click on any photo thumbnail in the gallery
3. Modal opens with EXIF data on left, photo on right
4. Look for "⬇️ Download Full Size" button in metadata panel
5. Click the button to download the original full-size image
6. Browser will prompt to save the file with original filename
